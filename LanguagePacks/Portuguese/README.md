# RimLingo v1.4.0 — Português

Instale esta pasta como um mod normal em RimWorld/Mods ou subscreva na Steam Workshop. Ative RimLingo e este pacote na lista de mods. Inclui inglês ↔ português. Não é necessário mover os modelos manualmente.

Install like a normal RimWorld mod: extract the ZIP into RimWorld/Mods, or subscribe on Steam Workshop after publication. Enable the base RimLingo mod and this expansion in the game mod list, with the base first. The base detects enabled expansion paths automatically, including numeric Workshop directories. No model files need to be copied into the base mod. Restart after enabling/disabling packs.

Select LibreTranslate → Use bundled offline engine. Other non-English pairs need the corresponding endpoint packs and may pivot through English, with slower or less accurate results.

Package ID: `gesvd.rimlingo.language.portuguese`. Model downloads and SHA-256 are recorded in manifest.json. Original model README files retain author, license and training-data attribution. The bundle omits unused Stanza/MiniSBD files and uses RimLingo’s existing sentence splitter; model weights are unchanged. Retain About/, models/, licenses/, manifest.json and this README when redistributing.
