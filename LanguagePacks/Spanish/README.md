# RimLingo v1.3.0 — Español

Instala esta carpeta como un mod normal en RimWorld/Mods o suscríbete en Steam Workshop. Activa RimLingo y este paquete en la lista de mods. Incluye inglés ↔ español. No hace falta mover los modelos manualmente.

Install like a normal RimWorld mod: extract the ZIP into RimWorld/Mods, or subscribe on Steam Workshop after publication. Enable the base RimLingo mod and this expansion in the game mod list, with the base first. The base detects enabled expansion paths automatically, including numeric Workshop directories. No model files need to be copied into the base mod. Restart after enabling/disabling packs.

Select LibreTranslate → Use bundled offline engine. Other non-English pairs need the corresponding endpoint packs and may pivot through English, with slower or less accurate results.

Package ID: `gesvd.rimlingo.language.spanish`. Model downloads and SHA-256 are recorded in manifest.json. Original model README files retain author, license and training-data attribution. The bundle omits unused Stanza/MiniSBD files and uses RimLingo’s existing sentence splitter; model weights are unchanged. Retain About/, models/, licenses/, manifest.json and this README when redistributing.
