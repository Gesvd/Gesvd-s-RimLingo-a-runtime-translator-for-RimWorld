# RimLingo v1.4.0 — 한국어扩展模组

像普通模组一样安装：把 ZIP 解压到游戏的 `Mods` 目录，或待作者发布后在 Steam 创意工坊订阅。在模组列表同时启用 **Gesvd的边缘翻译 / RimLingo** 和 **本语言扩展**，让基础模组排在扩展之前，然后按游戏提示重启。无需打开基础模组目录，也无需搬动模型或填写路径。

在翻译服务页选择 LibreTranslate 并启用内置离线引擎，从下拉菜单选择语言。其他非英语语言之间通常经英语中转，需要启用两端语言包；基础包已含英文→简体中文。禁用扩展后对应模型不再加载。

模型来源、版本和 SHA-256 见 manifest.json；原作者与许可声明见各模型 README 和 licenses/，请保留全部声明。本扩展与基础模组共享 Python，不需额外安装程序。发布到创意工坊时上传本目录（直接包含 About 和 models），不要上传 ZIP 本身或带额外父文件夹的目录。
